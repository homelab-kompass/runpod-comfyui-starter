# ComfyUI Starter DE/EN (Homelab-Kompass)

Bilingual Runpod template for ComfyUI. Builds on the official Runpod ComfyUI image (CUDA 12.8), adds a German and English quick start, official starter workflows, a model downloader for openly licensed weights, and secure password defaults.

- [Deutsch](README.de.md)
- [English](README.en.md)

**Author:** Michael Weidinger / Homelab-Kompass
**Guide:** https://homelab-kompass.pages.dev/ki-gpu-cloud/comfyui-runpod-einsteiger-anleitung/
**Image:** `ghcr.io/homelab-kompass/runpod-comfyui-starter`
